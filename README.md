# 玛法余烬 · 沙城纪元

原创浏览器 2D 动作角色扮演游戏。当前版本提供本地权威联机与完整非付费玩法循环：三职业成长、十一段主线、九个区域、采集打宝、八部位装备、PK/社交/行会战、世界 Boss 与沙巴克攻城。

## 运行

```bash
npm start
# 打开 http://localhost:8080
```

```bash
npm test
```

## 操作

| 操作 | 功能 |
| --- | --- |
| 鼠标 / 触屏 | 移动、锁定怪物、NPC、传送门 |
| W A S D | 自由移动 |
| Shift | 奔跑 |
| 空格 | 普通攻击 |
| 1–4 | 职业技能 |
| F1 / F2 | 生命药 / 魔法药 |
| G / H / P / F | 拾取 / 采集 / PK模式 / 社交 |
| B / C / Y / Q | 背包 / 角色与武器升级 / 成就 / 任务 |
| K / I / M | 技能学习 / 物品图鉴 / 九域地图与自动寻路 |
| V | 回城卷 |
| Esc | 关闭窗口 / 设置 |

## 项目结构

```text
index.html
css/style.css
js/
  audio.js       # Web Audio 战斗反馈
  config.js      # 职业、物品、怪物、地图、任务、成就
  entities.js    # 角色与单位状态
  game.js        # 战斗、AI、地图、采集、渲染与玩法规则
  network.js     # 本地权威服客户端与状态同步
  main.js        # 菜单、HUD、社交窗口与输入
server/
  local-server.mjs # 本地多人权威服务
assets/game/     # 游戏运行资源
tests/           # 玩法、真实 SSE、重连、持久化、压力与动画资源测试
```
