# 玛法余烬 · 沙城纪元

原创浏览器 2D 动作角色扮演游戏。当前版本提供完整的单机纵向循环：创建三职业角色、推进七段主线、探索五个区域、打宝换装、部位强化，最终挑战拥有预警法阵与狂暴阶段的沃玛教主。

## 运行

```bash
npm start
# 打开 http://localhost:8080
```

```bash
npm test
```

## 已完成玩法

- 战士、法师、道士三职业，各自四项技能与独立成长曲线
- 比奇城、盟重省、废弃矿洞、沃玛寺庙等五段区域流程
- 七段主线任务、怪物等级差经验衰减、掉落和 Boss 重生
- 五部位装备、职业与等级需求、五档稀有度、部位强化 +12
- 暴击、闪避、吸血、魔法防御、祝福效果和综合战力
- 连斩、七项成就、可领取奖励、击杀与最佳连斩记录
- 沃玛教主法阵预警、范围伤害、低血量狂暴
- 商店、仓库、药水、回城、死亡惩罚、自动存档与旧存档迁移
- 鼠标点选、WASD、触屏虚拟摇杆、键盘与移动端技能操作
- 自适应 HUD、战斗记录、Boss 血条、音效开关和全屏模式

## 操作

| 操作 | 功能 |
| --- | --- |
| 鼠标 / 触屏 | 移动、锁定怪物、NPC、传送门 |
| W A S D | 自由移动 |
| Shift | 奔跑 |
| 空格 | 短跳、规避 Boss 法阵 |
| 1–4 | 职业技能 |
| F1 / F2 | 生命药 / 魔法药 |
| B / C / Y / Q | 背包 / 角色强化 / 成就 / 任务 |
| V | 回城卷 |
| Esc | 关闭窗口 / 设置 |

## 项目结构

```text
index.html
css/style.css
js/
  audio.js       # Web Audio 战斗反馈
  config.js      # 职业、物品、怪物、地图、任务、成就
  entities.js    # 角色与单位状态
  game.js        # 战斗、AI、地图、渲染、强化与存档
  main.js        # 菜单、HUD、窗口与输入
assets/game/     # 游戏运行资源
tests/           # 配置、模拟战斗、动画资源测试
```

## 发布边界

本仓库当前是可完整游玩的单机浏览器版本。真正的商业联网发行仍需要独立的账号服务、服务器权威战斗、支付与订单、聊天审核、反作弊、热更新、埋点、隐私协议、版号与商店素材等外部基础设施；这些不应伪装成前端本地功能。
